# Banco de memoria del proyecto

Este directorio conserva hechos verificados sobre el dashboard financiero para orientar futuras ediciones de agentes.

## Archivos

- `product-context.md`: propósito, flujo observable, funcionalidades y límites del producto.
- `architecture.md`: frontend, backend, infraestructura y comunicación comprobados.
- `conventions.md`: naming, estructura, rutas, respuestas, pruebas y documentación observados.
- `decisions.md`: decisiones verificadas y motivos documentados o no encontrados.
- `current-state.md`: validaciones ejecutadas, gaps, riesgos pendientes y prioridades derivadas de evidencia.

Las afirmaciones deben mantenerse vinculadas a rutas, archivos, scripts, pruebas o comportamientos observables del repositorio. Si no existe evidencia, debe indicarse como no verificado.
